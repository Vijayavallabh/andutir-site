The Thesis

Creation is scaling. Validation is not.

Generative models can now write whole phage genomes — but in the landmark first effort, only a small fraction of AI-generated designs actually replicated. The field can produce candidate genomes faster than it can prove they work, and standard annotation tools cannot even fully annotate what has been generated.

Headline finding: prediction performance is highly context-dependent — no single tool wins everywhere. That is exactly why context-aware validation is the layer worth owning.

In a world where AI can generate infinite biological designs, the bottleneck isn't creation — it's validation. Without rigorous benchmarks, AI-designed phages are just sequences; without independent evaluation, clinical results are anecdotal; without standards, regulatory approval is guesswork.

The Project

What PhageHost-Bench is

The Benchmark

A public, leakage-controlled, multi-pathogen benchmark and leaderboard for phage-host prediction — systematic, reproducible, and context-aware by design.

The Context-Performance Matrix

A published map of which tools work in which scenarios, and the standard evaluation protocol that every new prediction tool must pass.

The Validation API

An open API that lets researchers validate their own predictions against the benchmark — and lets existing platforms integrate phage-specific validation directly.

Deliberate Focus

What we are not building

Every adjacent vector fails the same way: it builds infrastructure for a future that hasn't arrived, in markets that don't yet exist, against incumbents with more resources and more validation. So we don't compete with them — we measure their work.

The Approach

Three rings, one monopoly

The strategy is not to out-build anyone. It is to become the one thing no one else is: the rigorous, neutral, context-aware validator of phage-host prediction.

VALIDATE
Ring 1 · 0–18 months

The Academic Standard

Become the definitive benchmark for phage-host prediction. Publish the Context-Performance Matrix, set the evaluation protocol every new tool must pass, and open the validation API to researchers.

Ring 2 · 18–48 months

The Industrial Validation Layer

Partner with one synthetic phage company as their external benchmarking service — not a competitor, an assessor. Use that credibility to become the independent validator others need.

Ring 3 · 3–7 years

The Regulatory Infrastructure

Position as the neutral third-party validator for synthetic phage approvals, working with regulators on evaluation standards — the UL Labs of synthetic phage safety.

The Roadmap

From standard to gatekeeper to infrastructure

Phase 1 · 2025–2027

Establish the standard

Publish the definitive benchmark comparison, launch the open validation API, and build partnerships with 3–5 synthetic phage groups.

Phase 2 · 2027–2029

Become the gatekeeper

Secure regulatory recognition as a validation standard, expand to CRISPR-phage systems, and ship a real-time monitoring dashboard for clinical trials.

Phase 3 · 2029–2032

The infrastructure layer

Integrate with major platforms, help establish an international standards body, and license validation technology to pharmaceutical companies.
